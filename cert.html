🔐 Certificat HTTPS

Télécharge et installe ce certificat pour que Safari accepte la connexion sécurisée.

📥 Télécharger le certificat
  1. Touche "Autoriser" si demandé
  2. Va dans Réglages → Général → Gestion de l'appareil (ou "Profil")
  3. Touche le profil localhost → Installer
  4. Va dans Réglages → Général → Infos → Confiance des certificats
  5. Active localhost (DispoCam Dev)
⚠️ Après le test, tu peux supprimer ce certificat dans Réglages → Général → Gestion de l'appareil.

Ensuite, retourne sur :
https://192.168.0.18:5173
